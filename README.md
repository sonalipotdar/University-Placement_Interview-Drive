
# University Placement & Interview Drive Portal

## Project Overview
A Java-based placement management system that helps colleges manage students, visiting companies, placement eligibility and interview applications.

## Technology Stack
- Java 17
- Spring Boot
- Spring JDBC
- MySQL
- Maven
- Git and GitHub

## Project Modules
1. Student Management
2. Company Management
3. Application Management
4. Eligibility Management
5. Placement Statistics
6. Console Interface

## Team Collaboration
This project is developed collaboratively using GitHub feature branches and pull requests.
